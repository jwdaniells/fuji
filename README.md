# Fuji Recipes

A personal Fujifilm film simulation recipe library with scannable import cards and sample images.

## Structure
- `index.html` — recipe browser (GitHub Pages)
- `recipes/data.json` — recipe data and import status
- `cards/` — scannable PNG cards for the Fuji Recipes app
- `images/` — sample photos per recipe

## GitHub Pages
Enable Pages in repo Settings → Pages → Deploy from `main` branch.
